# 🚗 Garage Management System

A full-stack web application designed to streamline garage operations by managing employees, customers, vehicles, and service orders through a secure and user-friendly interface.

## 🌐 Live Demo

**Frontend:** https://garage-management-rho.vercel.app/

**Backend API:** https://garage-5.onrender.com/

---

## ✨ Features

- 🔐 Secure JWT Authentication
- 🔍 Search & Filter Functionality
- 👨‍🔧 Employee Management (CRUD)
- 👥 Customer Management (CRUD)
- 🚗 Vehicle Registration & Management
- 📋 Service Order Management
- 📊 Interactive Dashboard
- 📱 Responsive Design
- ⚡ RESTful API
- 💾 MySQL Database Integration
- ✅ Form Validation & Error Handling
- ☁️ Cloud Deployment

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/DEVA-BIR/garage-management-system.git
```

### Frontend

```bash
cd FrontEnd
npm install
npm run dev
```

### Backend

```bash
cd BackEnd
npm install
npm start
```
